# Calculadora Python + Pytest

Projeto desenvolvido em **Python** para praticar **Programação Orientada a Objetos** e **testes unitários com Pytest**.

## Objetivo

Implementar uma calculadora com operações matemáticas básicas e criar testes para verificar seu funcionamento.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Tratamento de erro para divisão por zero

## Testes

Foram implementados **13 testes** para verificar diferentes cenários:

- Números positivos
- Números negativos
- Zero
- Resultados decimais
- Divisão por zero
